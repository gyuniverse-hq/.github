## 🤝 Collaboration

- **소통:** 의견과 근거를 공유하고, 다른 의견에는 가능한 대안을 함께 제시합니다.
- **협업:** 작업 진행 상황과 일정 변경, 막힌 문제를 제때 공유합니다.
- **개발:** 주요 변경은 Branch와 Pull Request로 공유하고 Review를 거칩니다.
- **기록:** 중요한 결정과 변경 이유, 문제 해결 과정을 남깁니다.
